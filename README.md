# Recuperação Backend

Este repositório contém uma série de exercícios de programação em JavaScript/Node.js focados em lógica de programação, arrays, laços de repetição e processamento de dados.

## Estrutura do projeto

```text
Progamacao-Backend/
├── README.md
└── recuperacao_backend/
    ├── package.json
    ├── rec01_producao.js
    ├── rec02_materiais.js
    ├── rec03_oleo.js
    ├── rec04_vibracao.js
    ├── rec05_ciclos.js
    ├── rec06_media.js
    ├── rec07_setores.js
    ├── rec08_ferramentas.js
    ├── rec09_aproveitamento.js
    └── rec10_orcamento/
        ├── app.js
        └── funcoesOrcamento.js
```

## Como executar

1. Acesse a pasta do projeto:

```bash
cd recuperacao_backend
```

2. Instale as dependências:

```bash
npm install
```

3. Execute qualquer exercício com Node.js:

```bash
node rec07_setores.js
```

## Exercícios incluídos

- `rec01_producao.js` — produção e controle de dados
- `rec02_materiais.js` — cadastro e cálculo de materiais
- `rec03_oleo.js` — manipulação de dados de óleo
- `rec04_vibracao.js` — análise de vibração
- `rec05_ciclos.js` — controle de ciclos
- `rec06_media.js` — cálculo de médias
- `rec07_setores.js` — lista de setores da fábrica
- `rec08_ferramentas.js` — controle de ferramentas
- `rec09_aproveitamento.js` — aproveitamento e desempenho
- `rec10_orcamento/` — sistema de orçamento

## Dependências

O projeto utiliza a biblioteca `readline-sync` para leitura de entrada do usuário via terminal.

## Observações

Este repositório foi organizado para praticar conceitos fundamentais de JavaScript e lógica de programação com foco em exercícios de recuperação.
